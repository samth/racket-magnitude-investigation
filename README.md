# Racket float-complex magnitude investigation

See [FINDINGS.md](FINDINGS.md) for the performance table, accuracy results, generated-code analysis, and optimization opportunities.

The exact per-commit measurements for Matthew Flatt's Racket CS changes and the independent Typed Racket `zero?` specialization are in [results/matthew-series.md](results/matthew-series.md), with machine-readable data and raw logs in the same directory.

The repository contains:

- `benchmarks/original/`: the original benchmark programs.
- `benchmarks/variants/`: isolation variants used to attribute the performance differences.
- `results/`: raw x86, ARM, and MPFR output plus machine provenance.
- `experiments/`: optimizer expansions, disassembly, captured inputs, and Herbie reports.
- `patches/`: saved patches from the Racket primitive experiment.
- `checkouts/`: ignored worktrees for the three experimental branches.

Run a benchmark directly with `racket -y`, for example:

```sh
taskset -c 0 racket -y benchmarks/original/typed-scalar-simpl.rkt
```

The harness performs a warmup, runs five measured repetitions, reports cumulative allocation, and verifies the generated bytes against the reference implementation.
